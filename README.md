# ❄️ Shake the Globe

A small interactive web experience where you shake a snow globe and discover a little message. Built as a simple front-end project with HTML, CSS, and JavaScript.

## ✨ Features

-  Interactive snow globe
-  Random kindness messages
-  Simple winter-themed design

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- GitHub Pages
